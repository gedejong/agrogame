# Asset credits

Every downloaded file under `game/assets/materials/` and `game/assets/models/` has one row here: its path
(relative to `game/assets/`), the asset page it came from, its author(s), its licence, the download date and
any edits (ADR-022 decision 5). `game/tests/unit/test_asset_credits.gd` fails on a file without a row, a row
without a file, and a licence other than CC0 1.0 unless Edwin approved it.

Poly Haven states CC0 1.0 for every asset (<https://polyhaven.com/license>); each asset page below says
"CC0" (checked 2026-11-25). Binaries live in Git LFS (see `docs/contributing.md`).
